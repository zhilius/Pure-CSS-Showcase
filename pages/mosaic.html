How it works

Grid layout

CSS Grid creates the mosaic structure. Cells span multiple columns and rows using grid-column and grid-row:

.mosaic {  display: grid;  grid-template-columns: repeat(4, 1fr);  grid-template-rows: repeat(3, 28px);  gap: 4px;}.m1 { grid-column: span 2; grid-row: span 2; }.m2 { grid-column: span 2; }.m5 { grid-column: span 2; }.m7 { grid-column: span 3; }

Staggered entrance

Each cell fades in with a staggered animation-delay, creating a wave-like reveal:

@keyframes fadein {  from { opacity: 0; transform: scale(.8); }  to   { opacity: 1; transform: scale(1); }}.m1 { animation-delay: 0s; }.m2 { animation-delay: .1s; }/* ... up to .m8 with .7s delay */

The role="img" and aria-label attributes describe the visual content to assistive technology.
