How it works

Five faces are placed around a circle using rotateY(Ndeg) translateZ(radius). With transform-style: preserve-3d, they exist in 3D space and the whole carousel rotates:

.carousel { transform-style: preserve-3d; animation: carousel-spin 8s linear infinite; }.cf-1 { transform: rotateY(0deg) translateZ(80px); }.cf-2 { transform: rotateY(72deg) translateZ(80px); }.cf-3 { transform: rotateY(144deg) translateZ(80px); }.cf-4 { transform: rotateY(216deg) translateZ(80px); }.cf-5 { transform: rotateY(288deg) translateZ(80px); }@keyframes carousel-spin { to { transform: rotateY(360deg); } }

360° / 5 faces = 72° apart. backface-visibility: hidden prevents flickering.
