CSS Glass

How it works

Glass panel

The glass effect uses backdrop-filter: blur() on a semi-transparent panel. This blurs everything behind the panel, creating the frosted glass look:

.glass-panel {  backdrop-filter: blur(12px);  -webkit-backdrop-filter: blur(12px);  background: rgba(255,255,255,0.12);  border: 1px solid rgba(255,255,255,0.25);  border-radius: 12px;}

Animated blobs

Two colorful blobs float behind the glass panel with a slow drifting animation, making the backdrop-filter effect more visible:

.gb1 {  width: 70px; height: 70px;  background: var(--c4);  animation: glass-drift 4s ease-in-out infinite alternate;}.gb2 {  width: 50px; height: 50px;  background: var(--c5);  animation: glass-drift 5s ease-in-out infinite alternate-reverse;}@keyframes glass-drift {  from { transform: translate(0,0); }  to   { transform: translate(15px,15px); }}

Gradient background

The stage itself has a gradient background, providing a colorful backdrop for the glass effect to shine through.
