⧉ Container Query

How it works

Container queries let elements respond to their own container's size instead of the viewport. First, define a containment context:

.cq-demo {  container-type: inline-size;  container-name: card;  resize: horizontal;  overflow: auto;}
  • container-type: inline-size — enables querying the inline (width) size
  • container-name — gives the container a name for @container queries
  • resize: horizontal — lets the user drag to resize (for demo purposes)

Responsive breakpoints

Styles inside @container apply only when the container meets the condition:

@container card (min-width: 200px) {  .cq-demo { background: var(--color-background-tertiary); }  .cq-inner { flex-direction: row; gap: 12px; }  .cq-icon { font-size: 36px; }}@container card (min-width: 280px) {  .cq-demo { background: rgba(83,74,183,0.08); }  .cq-inner { gap: 16px; }}

Unlike media queries (which depend on the viewport), container queries make truly reusable, self-contained responsive components.
