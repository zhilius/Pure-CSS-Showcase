How it works

Tooltips are built with attr() and ::after. The data-tip attribute holds the text, and the pseudo-element displays it on hover:

.tt-el { position: relative; cursor: help; }.tt-el::after { content: attr(data-tip); position: absolute; bottom: calc(100% + 6px); left: 50%; translate: -50% 0; opacity: 0; pointer-events: none; transition: opacity .2s; }.tt-el:hover::after { opacity: 1; }

The attr() function reads the value of data-tip and uses it as the content of the pseudo-element. pointer-events: none prevents the tooltip from interfering with hover.
