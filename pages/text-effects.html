How it works

Gradient text

A background gradient is clipped to the text using background-clip: text with -webkit-text-fill-color: transparent. The background pans horizontally to animate:

.gradient-text {  background: linear-gradient(90deg, var(--c1), var(--c4), var(--c2));  background-size: 200%;  -webkit-background-clip: text;  -webkit-text-fill-color: transparent;  background-clip: text;  animation: hue 3s linear infinite;}@keyframes hue {  to { background-position: 200%; }}

Typewriter

white-space: nowrap combined with overflow: hidden and a steps() animation reveals text character by character. The blinking cursor is a border-right:

.typewriter {  overflow: hidden;  white-space: nowrap;  border-right: 2px solid var(--c5);  width: 0;  animation: type 3s steps(20) 0.5s forwards,             blink .6s step-end infinite;}@keyframes type { to { width: 14ch; } }@keyframes blink { 50% { border-color: transparent; } }

Glitch

Two pseudo-elements (::before, ::after) duplicate the text using attr(data-text). Each is clipped to a horizontal strip and offset with a jitter animation:

.glitch::before {  color: var(--c3);  clip-path: polygon(0 0, 100% 0, 100% 35%, 0 35%);  animation: glitch-t .4s infinite;}.glitch::after {  color: var(--c5);  clip-path: polygon(0 65%, 100% 65%, 100% 100%, 0 100%);  animation: glitch-b .4s .2s infinite;}
