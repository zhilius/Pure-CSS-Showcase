How it works

CSS counters let you number elements automatically. Three steps:

.counter-ol { counter-reset: step; }.counter-ol li { counter-increment: step; }.counter-ol li::before { content: counter(step) ". "; color: var(--c1); font-weight: 600; }
  • counter-reset — initializes the counter on the parent
  • counter-increment — increments the counter for each element
  • counter() — outputs the current value as content

Unlike list-style, CSS counters let you fully customize numbering with colors, fonts, and text around the number. They also support nested counters (e.g., 1.1, 1.2).
