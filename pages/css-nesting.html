How it works

CSS nesting lets you write nested selectors inside a parent rule using the & nesting selector. It mirrors the structure of your HTML, making styles more readable:

.card { background: #fff; & .title { font-weight: bold; } /* .card .title */ & > p { color: gray; } /* .card > p */ &:hover { scale: 1.02; } /* .card:hover */ }

The & refers to the parent selector. You can nest media queries, pseudo-classes, and compound selectors. Browser support: Chrome 120+, Safari 17.2+, Firefox 117+.
