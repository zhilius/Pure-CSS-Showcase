How it works

A ::before pseudo-element sits behind the main element with a slightly larger size (inset: -4px). It uses conic-gradient() and rotates continuously:

.conic-border { position: relative; z-index: 0; }.conic-border::before { content: ''; position: absolute; inset: -4px; border-radius: 50%; background: conic-gradient(var(--c1), var(--c4), var(--c2), var(--c5), var(--c1)); z-index: -1; animation: conic-rotate 2s linear infinite; }@keyframes conic-rotate { to { transform: rotate(360deg); } }

The main element's background: var(--color-background-primary) covers the center, making the gradient visible only as a border.
