How it works

CSS filter applies visual effects to an element. Each square uses a different filter function:

.fl-blur { filter: blur(2px); }.fl-grayscale { filter: grayscale(1); }.fl-hue { filter: hue-rotate(180deg); }.fl-contrast { filter: contrast(2); }.fl-bright { filter: brightness(1.5); }

Filters can be combined: filter: brightness(1.2) contrast(1.1) saturate(1.3);
