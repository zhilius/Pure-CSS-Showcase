How it works

CSS-only illustrations use div elements and pure CSS for positioning, shapes, and colors — no images, SVG, or canvas:

.ill-robot { position: relative; width: 60px; height: 80px; }.ill-head { width: 32px; height: 28px; background: var(--c1); border-radius: 8px 8px 4px 4px; }.ill-eye { width: 5px; height: 5px; background: #fff; border-radius: 50%; }.ill-body { width: 44px; height: 32px; background: var(--c4); border-radius: 4px 4px 8px 8px; }.ill-arm { position: absolute; width: 6px; height: 22px; background: var(--c1); border-radius: 3px; }.ill-leg { width: 6px; height: 18px; background: var(--c1); border-radius: 3px; }

By combining width/height, border-radius, position: absolute, and colors, you can create complex illustrations without any external resources.
