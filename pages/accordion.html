What is pure CSS?
CSS features that work without JavaScript, like animations, transitions, and modern layout.
Is it responsive?
Yes! Media queries, container queries, and clamp() make it fully responsive.
Can I contribute?
Fork the repo, add your demo, and open a pull request on GitHub!

How it works

The native <details> and <summary> HTML elements provide built-in show/hide functionality. Pure CSS handles the styling:

.ac-item { background: var(--color-background-secondary); border-radius: 8px; overflow: hidden; }.ac-item summary { padding: 8px 12px; cursor: pointer; user-select: none; }.ac-item[open] summary { background: var(--color-background-tertiary); }

The [open] attribute is automatically toggled by the browser when the user clicks the <summary>. No :checked hacks or JavaScript needed.
