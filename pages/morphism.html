How it works

Morphing shape

The geo-inner element transitions between border-radius values, rotations, and background colors:

@keyframes morph {  0%   { border-radius: 8px;    transform: rotate(0deg);   background: var(--c1); }  25%  { border-radius: 50%;    transform: rotate(90deg);  background: var(--c2); }  50%  { border-radius: 8px 50%; transform: rotate(180deg); background: var(--c3); }  75%  { border-radius: 0 50% 50% 0; transform: rotate(270deg); background: var(--c4); }  100% { border-radius: 8px;    transform: rotate(360deg); background: var(--c1); }}

Orbit

The orbit ring uses position: absolute inside a relative container and spins continuously. The dot is placed at the top of the ring using top and left: 50%, creating a satellite effect:

.orbit-ring {  position: absolute;  animation: spin 3s linear infinite;}.orbit-dot {  position: absolute;  top: -5px;  left: calc(50% - 5px);}

The spin keyframe is reused from the loaders page — a simple 360° rotation.
