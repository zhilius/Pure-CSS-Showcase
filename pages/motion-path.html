How it works

The offset-path CSS property lets an element follow an SVG path without any JavaScript:

.path-runner {  width: 18px; height: 18px;  background: var(--c1);  border-radius: 50%;  offset-path: path("M 25,55 C 25,12 175,12 175,55 C 175,98 25,98 25,55");  offset-distance: 0%;  animation: race 3s linear infinite;}@keyframes race {  to { offset-distance: 100%; }}

How the path works

The SVG path uses a cubic bezier curve (C). The same path is drawn visually with a dashed stroke on the SVG and is assigned to the dot via offset-path. Animating offset-distance from 0% to 100% moves the dot along the entire curve.

Accessibility

The SVG is hidden from screen readers (aria-hidden="true"), while the moving dot has aria-label describing the animation.
