How it works

Toggle switches

A hidden checkbox controls a styled slider via the adjacent sibling combinator +. The :checked pseudo-class changes the slider's position and color:

.toggle input { opacity: 0; }.slider-t::before {  content: '';  width: 18px; height: 18px;  transition: transform .3s;}input:checked + .slider-t {  background: var(--c1);}input:checked + .slider-t::before {  transform: translateX(20px);}

Skeleton loader

A shimmer effect is created with a ::after pseudo-element that slides across a gradient background:

.skel {  background: linear-gradient(90deg,    var(--color-background-secondary) 25%,    var(--color-background-tertiary) 50%,    var(--color-background-secondary) 75%);}.skel::after {  content: '';  position: absolute;  inset: 0;  background: linear-gradient(90deg,    transparent, rgba(128,128,160,0.08), transparent);  animation: shimmer 1.5s infinite;}@keyframes shimmer {  from { transform: translateX(-100%); }  to   { transform: translateX(100%); }}

role="status" and aria-label inform assistive technology that content is being loaded.
