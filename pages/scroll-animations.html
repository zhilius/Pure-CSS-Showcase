How it works

animation-timeline: scroll(self) links an animation to the scroll position of the element itself, no JavaScript needed:

.sda-fill { animation: sda-fill linear; animation-timeline: scroll(self); transform-origin: left; }@keyframes sda-fill { from { transform: scaleX(0); } to { transform: scaleX(1); } }

The progress bar scales from 0 to 1 as the user scrolls the container. Browser support: Chrome 115+, Edge 115+, Firefox 128+.
