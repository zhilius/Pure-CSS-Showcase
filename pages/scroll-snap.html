How it works

CSS scroll snap makes scroll containers snap to specific positions. The key properties:

.snap-gallery { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; }.snap-item { scroll-snap-align: start; }
  • scroll-snap-type: x mandatory — the container snaps to snap positions on the x-axis
  • scroll-snap-align: start — each child snaps to the start edge of the container
  • scroll-padding — adds spacing before the snap position (optional)

No JavaScript needed for swipeable, snap-able galleries.
