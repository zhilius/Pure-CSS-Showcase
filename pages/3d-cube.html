How it works

A 3D cube is built entirely with CSS transforms. Six faces are positioned in 3D space using translateZ and rotateY/rotateX, then the whole cube rotates via a keyframe animation.

Perspective

The parent element sets the 3D stage with perspective, creating depth:

.cube-scene {  perspective: 600px;}

Preserve 3D

The cube container keeps children in 3D space so transforms accumulate:

.cube {  transform-style: preserve-3d;}

Face positioning

Each face is absolutely positioned and moved to its side of the cube. A 100px cube needs 50px translation (half the width):

.cube-front  { transform: translateZ(50px); }.cube-back   { transform: rotateY(180deg) translateZ(50px); }.cube-right  { transform: rotateY(90deg) translateZ(50px); }.cube-left   { transform: rotateY(-90deg) translateZ(50px); }.cube-top    { transform: rotateX(90deg) translateZ(50px); }.cube-bottom { transform: rotateX(-90deg) translateZ(50px); }

Rotation animation

@keyframes cube-rotate {  from { transform: rotateX(-25deg) rotateY(0deg); }  to   { transform: rotateX(-25deg) rotateY(360deg); }}

A slight rotateX(-25deg) tilt makes all three visible faces (front, top, right) clearly distinguishable as the cube spins.
