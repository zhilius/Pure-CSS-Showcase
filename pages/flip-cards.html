How it works

The flip effect is built with four key CSS properties:

  • perspective — adds 3D depth to the parent container
  • transform-style: preserve-3d — allows children to exist in 3D space
  • backface-visibility: hidden — hides the back face when facing away
  • rotateY(180deg) — flips the inner container on hover
.flip-card {  perspective: 600px;}.flip-inner {  transition: transform .6s;  transform-style: preserve-3d;}.flip-card:hover .flip-inner {  transform: rotateY(180deg);}.flip-front,.flip-back {  backface-visibility: hidden;}.flip-back {  transform: rotateY(180deg);}

The front and back are absolutely positioned on top of each other. The back is pre-rotated 180° so it appears when the inner container flips.
