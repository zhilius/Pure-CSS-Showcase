How it works

All effects rely on CSS transition on the button, with state changes triggered by :hover.

Lift

A simple translateY(-2px) on hover gives a floating feel:

.btn-fill:hover {  transform: translateY(-2px);}

Fill

The border retains its color while the background fills in on hover:

.btn-outline:hover {  background: var(--c2);  color: #fff;}

3D press

A box-shadow creates a 3D bevel. On hover the shadow shrinks and the button moves down:

.btn-3d {  box-shadow: 0 4px 0 #712B13;}.btn-3d:hover {  transform: translateY(3px);  box-shadow: 0 1px 0 #712B13;}

Slide in

A ::after pseudo-element slides in from the left behind the text using translateX:

.btn-slide::after {  transform: translateX(-100%);  transition: transform .3s;}.btn-slide:hover::after {  transform: translateX(0);}
