How it works

Floating label

The label is positioned over the input using position: absolute. When the input is focused or has content (:not(:placeholder-shown)), the label floats up:

.inp-wrap label {  position: absolute;  top: 9px;  left: 12px;  transition: all .2s;  pointer-events: none;}.inp-wrap input:focus ~ label,.inp-wrap input:not(:placeholder-shown) ~ label {  top: -10px;  font-size: 11px;  color: var(--c1);}

The placeholder=" " (a single space) is a hack to make :placeholder-shown work even though we don't want a visible placeholder.

Validation

CSS pseudo-classes change the border color based on validity:

.inp-wrap input:valid:not(:placeholder-shown) {  border-color: var(--c2); /* green */}.inp-wrap input:invalid:not(:placeholder-shown) {  border-color: #E24B4A; /* red */}

The newer :user-valid and :user-invalid pseudo-classes are also included for browsers that support them — they only trigger after the user has interacted with the field.
