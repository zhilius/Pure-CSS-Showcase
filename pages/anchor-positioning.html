How it works

CSS anchor positioning lets you position one element relative to another without JavaScript. First, name the anchor:

.anchor-target { anchor-name: --a-el; }

Then, position the tooltip relative to the anchor using the anchor() function:

.anchor-popup { position: absolute; top: anchor(--a-el bottom); left: anchor(--a-el center); translate: -50% 8px; }

Browser support: Chrome 125+, Edge 125+. Falls back to a reasonable default in other browsers.
