How it works

Each bar fill has a fixed width percentage via inline style, but starts invisible because of a transform: scaleX(0) animation that animates to full width:

.bar-fill {  height: 100%;  transform-origin: left;  animation: grow 1.5s cubic-bezier(.4,0,.2,1) both;}@keyframes grow {  from { transform: scaleX(0); }}

Staggered delays

Each bar gets a progressively longer animation-delay so they load in sequence:

.bar-c1 { animation-delay: 0s; }.bar-c2 { animation-delay: .1s; }.bar-c3 { animation-delay: .2s; }.bar-c4 { animation-delay: .3s; }

Accessibility

Each track uses role="progressbar" with aria-valuenow, aria-valuemin, and aria-valuemax for screen reader support.
