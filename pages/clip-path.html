How it works

The clip-path property clips an element into any arbitrary shape using a polygon. Each shape is defined by percentage coordinates:

Hexagon

.cs-hexagon {  clip-path: polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%);}

Star

.cs-star {  clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%,                     79% 91%, 50% 70%, 21% 91%, 32% 57%,                     2% 35%, 39% 35%);}

Chevron

.cs-chevron {  clip-path: polygon(100% 0%, 75% 50%, 100% 100%,                     0% 100%, 25% 50%, 0% 0%);}

Diamond

.cs-diamond {  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);}

Interactive bonus

Hover any shape — the shape scales up slightly and fades for a subtle interactive effect:

.clip-shape:hover {  transform: scale(1.12);  opacity: 0.85;}
