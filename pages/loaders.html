How it works

Each loader uses @keyframes and a looping animation to create the loading illusion. No JavaScript or external libraries are used.

Spinner

A bordered circle with border-top-color set to an accent color. Rotating it 360° creates the classic spinner:

@keyframes spin {  to { transform: rotate(360deg); }}

Pulse

A circle that scales up and down while fading:

@keyframes pulse {  0%, 100% { transform: scale(1); opacity: 1; }  50%      { transform: scale(.5); opacity: .4; }}

Bounce

Three dots bouncing at staggered delays. Each <span> gets a different animation-delay:

@keyframes bounce {  0%, 100% { transform: translateY(0); }  50%      { transform: translateY(-16px); }}

Wave

Five bars of increasing height, each with a progressive animation-delay to create a rippling effect:

@keyframes wave {  0%, 100% { transform: scaleY(.4); }  50%      { transform: scaleY(1); }}

Accessibility

role="status" and aria-label inform screen readers. A prefers-reduced-motion media query in animations.css disables all motion for users who prefer it.
