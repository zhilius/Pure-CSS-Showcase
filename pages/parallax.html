How it works

Parallax uses perspective on the parent and translateZ() on layers. Elements with negative translateZ move slower than the scroll, creating depth:

.parallax-scene { perspective: 1px; overflow-y: auto; }.pl-back { transform: translateZ(-1px) scale(2); }.pl-front { transform: translateZ(0); }

scale(2) compensates for the element being pushed back by translateZ(-1px), keeping it at the same visual size.
