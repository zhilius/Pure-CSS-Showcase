:has() changes the parent container's border

How it works

Parent-aware styling

The :has() pseudo-class applies styles to a parent when it contains a child matching a selector. Here, the <form> gets a highlighted border when any checkbox inside is checked:

.has-form:has(input:checked) {  border-color: var(--c1);  box-shadow: 0 0 0 3px rgba(83,74,183,0.15);}

Individual chips

Each chip is a <label> wrapping a hidden checkbox. When checked, the chip itself is styled via :has() on the label:

.has-chip:has(input:checked) {  background: var(--c1);  color: #fff;  border-color: var(--c1);}

This is a pure CSS interactive pattern — no JavaScript required to track state or apply classes.
