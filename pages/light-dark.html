Auto-switching colors

How it works

The light-dark() CSS function returns one of two colors based on the user's system color scheme — no media query needed:

:root { color-scheme: light dark; }body { background: light-dark(white, #1a1a2e); color: light-dark(#1a1a2e, #e8e8e8); }

It requires color-scheme to be set on the element. The first argument is the light color, the second is the dark color. Browser support: Chrome 122+, Firefox 128+, Safari 18+.
