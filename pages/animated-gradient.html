Animated Gradient

How it works

Before @property, you couldn't smoothly animate CSS gradients because the browser treats gradient components as discrete values. The @property at-rule registers a custom property with a specific type, enabling smooth transitions and animations.

Register the property

The angle is registered as a <angle> type that CSS can interpolate:

@property --grad-angle {  syntax: '<angle>';  inherits: false;  initial-value: 0deg;}

Use it in a gradient

.grad-orb {  width: 90px;  height: 90px;  border-radius: 50%;  background: linear-gradient(var(--grad-angle),    var(--c1), var(--c4), var(--c2), var(--c5));  animation: spin-grad 3s linear infinite;}

Animate it

@keyframes spin-grad {  to { --grad-angle: 360deg; }}

The browser now understands --grad-angle is an angle, so it smoothly interpolates from 0deg to 360deg — creating a seamless rotating gradient that was previously only possible with JavaScript or by animating background-position with limited results.

Browser support: @property is supported in all modern browsers (Chrome 85+, Firefox 128+, Safari 16.4+).
