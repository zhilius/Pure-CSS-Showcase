# Pure CSS Showcase

Interactive showcase of CSS techniques — **zero JavaScript**.

All animations, layouts, interactions, and visual effects are built exclusively with CSS. Each feature includes a detail page explaining how it works with code snippets.

## Features

- **Animated Loaders** — spinner, pulse, bounce, wave
- **Morphism & Orbit** — shape morphing + orbiting dot
- **Button Effects** — lift, fill, 3D press, slide
- **Text Effects** — gradient, typewriter, glitch
- **Progress Bars** — animated with staggered delays
- **Flip Cards** — 3D flip on hover
- **Animated Mosaic** — CSS Grid + staggered fade-in
- **Floating Label + Validation** — pure CSS form styling
- **Native Toggles + Skeleton Loader** — checkbox hack + shimmer
- **Glassmorphism** — backdrop-filter blur
- **Motion Path** — offset-path animation
- **:has() Selector** — parent-aware styling
- **3D Cube** — perspective + preserve-3d
- **Container Queries** — size-based responsive components
- **clip-path Art** — polygon shapes
- **Animated Gradient** — @property custom property animation
- **CSS Parallax** — perspective + translateZ
- **3D Carousel** — rotateY + translateZ gallery
- **Anchor Positioning** — CSS anchor() positioning
- **light-dark()** — automatic theme colors
- **Accordion** — details/summary element

## Getting started

Open `index.html` in any modern browser. No build tools, no servers, no JavaScript.

```
git clone https://github.com/zhilius/Pure-CSS-Showcase.git
cd Pure-CSS-Showcase
start index.html
```

## Browser support

Modern browsers: Chrome, Firefox, Safari, Edge. Some features (anchor positioning, container queries, scroll-driven animations) require the latest versions.
